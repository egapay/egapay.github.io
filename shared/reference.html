01Prose

Body copy sits at ink-2 against the panel, capped at a readable measure. Inline links take the signal amber, and emphasis drops to the quietest ink so it reads as an aside rather than a shout. Inline code gets a panel chip.

A third-level heading

  • Unordered items take an amber marker.
  • Line height and spacing are tuned for long-form reading, not for dense UI.
  1. Ordered items switch the marker to the mono face.
  2. This keeps numbered process steps feeling instrumented.

02Report embeds

Embeds take a fixed height on narrow screens and hand sizing to aspect-ratio from 768px up, replacing the fixed 75vh that distorted every inline report.
